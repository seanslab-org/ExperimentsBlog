# Sean's Lab — Brand Color Specification

## Color Palette

### Primary — Amber Orange
```
#F28A1A
```
Logo, headings, active links, primary CTAs.

### Secondary — Deep Wood
```
#1B4332
```
Code blocks, tags, terminal prompts, secondary UI elements.

### Background — Ink Night
```
#0A0A0F
```
Page background, card backgrounds.

### Accent — Tech Gold
```
#C9A227
```
Link hover states, buttons, emphasis text, highlighted keywords.

### Body Text
```
#E0E0E0
```
Default paragraph text on dark background.

### Muted Text
```
#9A9A9A
```
Secondary descriptions, timestamps, metadata.

---

## Usage Map

| Element | Color | Hex |
|---------|-------|-----|
| Logo "Sean's Lab" | Amber Orange | `#F28A1A` |
| Page background | Ink Night | `#0A0A0F` |
| Body text | Light Gray | `#E0E0E0` |
| Headings / links | Amber Orange | `#F28A1A` |
| Link hover / buttons | Tech Gold | `#C9A227` |
| Code blocks / tags | Deep Wood | `#1B4332` |
| Muted / secondary text | Gray | `#9A9A9A` |
| Terminal prompt path | Wood Green | `#4A9A6E` |

---

## Do Not Use

- Pure blue `#0000FF` or deep blue `#003366` as primary or secondary
- Large areas of pure black `#000000` (use `#0A0A0F` instead for warmth)
- Neon or saturated cyan/aqua tones

---

## Logo Typography

- Font: `Courier New` or monospace equivalent
- Weight: 700 (bold)
- Letter spacing: 2-3px
- Subtitle: 13px, `#C9A227`, letter spacing 6px
